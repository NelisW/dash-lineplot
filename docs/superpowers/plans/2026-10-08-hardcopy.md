# dash-lineplot Hardcopy Output Implementation Plan

Markdown flavour: LaTeX-conversion-safe (ASCII only, LF line endings),
with Pandoc/Puppeteer PDF front matter, matching the spec.

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Ctrl+Alt+H keystroke writes the graphs of the visible tab to
A4, 300 dpi PNG pages, and graphs of `Height` 200 or less drop their
readout column.

**Architecture:** Python changes in `dash-lineplot.py` decide which graphs
have boxes, wrap each tab in a `graph-tab` div carrying the tab name and
`HardcopyGraphsPerPage`, and register callbacks only where their
components exist. A new browser asset, `assets/hardcopy.js`, does all the
hardcopy work client-side with `Plotly.toImage`, a canvas, and the File
System Access API.

**Tech Stack:** Python 3.14, Dash 4.4, Plotly, pandas; plain browser
JavaScript; pytest and node's built-in `node:test` for tests.

**Spec:** `docs/superpowers/specs/2026-10-08-hardcopy-design.md`

  working tree; the user commits.

  (Git Bash: `/c/Users/nwillers/AppData/Local/anaconda3/envs/dashplot/python.exe`),

- `pathlib.Path` only, no `os.path`; no hard-coded paths, drive letters or

- Box threshold: a graph has boxes when its block `height > 200`

- Keystroke: Ctrl+Alt+H (`event.ctrlKey && event.altKey && event.code === 'KeyH'`).
- File names: `<name>.png` for one page, `<name>-p1.png`, `<name>-p2.png`,
  ... for several. Names containing any of `<>:"/\|?*` are refused.
- Unsupported-browser message, verbatim: `Hardcopy needs Chrome or Edge, opened at a localhost address`.
- Test servers on ports 8120 upward, never 8050; stop only processes the
  task started.
- Match the surrounding code style: camelCase Python names, comment density
  as in `dash-lineplot.py` and `assets/graphsync.js`.

## Review Focus

1. `HardcopyGraphsPerPage` present but not a positive integer (`0`, `-2`,
   `2.5`, `abc`, blank): treated exactly as absent, no error. Pinned in
   Task 2 (`test_hardcopy_per_page_values`).
1. Ctrl+Alt+H pressed again while the name box is already open: no second
   box. Pinned in Task 5, check 6.
1. Target folder already holds some of the page files and the user
   declines overwrite: nothing written. Pinned in Task 5, check 4.
1. Graph zoomed with the mouse before the keystroke: the page shows the

   Task 6, check 2.

**Files:**

**Interfaces:**
- Produces, inside the file's one immediately invoked function, and
  exported only under node by a guard placed before any browser wiring
  (`if (typeof module === 'object' && module.exports) { module.exports = {...}; return; }`):
    - `cleanName(raw: string) -> string | null`: trimmed, one trailing
      `.png` removed case-insensitively; `null` when the result is empty
      or contains any of `<>:"/\|?*`.
    - `pageFileNames(name: string, count: number) -> string[]`.
    - `layoutPages(heights: number[], perPage: number | null, pageHeight: number) -> Array<Array<{index: number, y: number, h: number}>>`,
      CSS px. With `perPage`: slots of `pageHeight / perPage`, `y = k * slot`,
      `h = slot`. Without: top-down at own height, a graph that does not
      fit starts a new page, a single graph taller than `pageHeight` gets
      `h = pageHeight`.
    - `crc32(bytes: Uint8Array) -> number` (unsigned, standard PNG CRC).
    - `setPngDpi(png: Uint8Array, dpi: number) -> Uint8Array`: inserts a
      `pHYs` chunk right after `IHDR`, or replaces an existing one; pixels
      per metre `Math.round(dpi / 0.0254)`.
    - `PAGE = {widthMm: 210, heightMm: 297, marginMm: 10, dpi: 300}` and
      `mmToCss(mm) = mm / 25.4 * 96`, `mmToPx(mm) = Math.round(mm / 25.4 * 300)`.

Behaviour is the spec's "Sequence", "Page geometry", "Layout",
"Rendering", "300 dpi marking" and "Writing" sections, in that order. The
points the spec leaves open are decided here:

- Visible tab: the first `.graph-tab` with `offsetParent !== null`;

- Printed width: `Math.floor(mmToCss(190))` CSS px; printable height
  `mmToCss(277)`. Draw position of a slot: x `mmToPx(10)`, y
  `mmToPx(10) + Math.round(slot.y * 300 / 96)`.
- On-screen height of a graph for the default layout: `gd.offsetHeight`.
- Existence check and overwrite prompt:
  `confirm('Overwrite ' + n + ' existing file(s) in this folder?')`.
- While the box is open, a second Ctrl+Alt+H is ignored.

There is no unit test for this task: it is DOM, canvas and file-system
wiring. It is checked in the browser with a stand-in folder handle, so
the native dialog is not needed.
